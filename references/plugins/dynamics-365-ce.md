# Microsoft Dynamics 365 CE

No released plugin. Do not configure syncs from this page. If a connection for this app exists in an account, check its real plugin via `DATA_VIEWS.CONNECTION.PLUGIN_FQN` and copy parameters from a UI-created sync.

For Dynamics 365 CE (Dataverse) data, use the `dynamics_365_synapse_link` plugin, which supports Dynamics 365 CE apps (Sales, Customer Service, Marketing, Field Service, Project Operations) via Azure Synapse Link. See `dynamics_365_synapse_link.md`.
